## 1. 当前结论与交付范围

**确定：综合框架与交互研究协议初稿已完成。** 主体第 1—8 节约 8,100 个汉字，英文摘要 233 词，10 条原始论文引用。已完成文献核验、起草及两轮内部问题检查；不是外部专家盲审或期刊评审。

**不确定：三个组件同时开启是否优于其中两个，是否具备独立论文所需的实证增量。** 本稿没有已实现系统、真实运行日志或性能结果。用户授权的是写作与自查，文中的实验步骤是后续研究协议，没有由此实际启动收费模型实验、对外投稿或发布。

一句话解释研究价值：不能因为规则、事实核查、反思分别看起来有用，就认定三者放在一起更好；这篇要查清它们何时互补，何时互相拖累，以及多花的钱是否值得。

## 2. 原路线理念怎样进入论文

| 原路线说法 | 论文中的可观察对象 | 为什么这样处理 |
|---|---|---|
| 荣辱观 | C：明确的允许、禁止和动作前置条件 | 可以检查是否遵守，无须猜测模型有没有羞耻感或责任心 |
| 第一性原理 | K：区分已支持信息、假设、冲突和待查项 | 可以核验依据与遗漏，不把一句“从本质出发”当作能力证明 |
| 三省吾身 | F：预测与实际结果比较、有限修正、重新验证 | 可以测量真实改错与新错误，无须用反思字数代表进步 |

这些是研究者的操作化选择，不是哲学理论的完整翻译，也不声称模型具有人类道德心理。正文保留理念来源，同时把结论约束到可观察机制。

已检查第 01、03、04、05 篇的研究问题与方法边界。本篇不重复提出记忆治理、行动反思或主张证据关联；它把基础组件冻结为实验因素，只检验新增的组合交互。配套研究仍是未发表方法稿，不作为实证来源。

## 4. 自查中发现并直接修正的问题

| 主要风险 | 已完成的修改 | 后续仍需的验证 |

| 把哲学或文化用语写成模型机制 | 建立操作性映射，删除人格、道德心理或“更聪明”的效果推断 | 按行为记录评分 |
| 分层框架已有近邻 | 显式纳入 Policies on Paths、AEI 和 Maat，避免首创措辞 | 可运行近邻与适配差异复核 |
| 与第 03—05 篇重复发表 | 增加研究分工和数据重叠披露规则，本稿只检验组合增量 | 正式研究共同登记任务、轨迹及报告范围 |
| 全开对全关无法识别交互 | 保留 2×2×2 八条件，主要交互固定为 C=1 时 K 与 F 的差分之差 | 全部必要单元和家族配对数据 |
| 关闭机制被误认为模型不再具备该能力 | 明确开关只控制外部机制；结果解释为分配效果 | 报告实际执行检查，但不按服从情况删样本 |
| K 关闭时 F 的职责不明确 | 八条件接口表明确 F 可独立给出带观测编号的建议，只有 K 开启才更新显式状态 | 001、101、011、111 的逐项接口试例 |
| 把错误停机当作治理成功 | 联合成功独立评分，可完成任务提前停机计失败 | 正常、应停止、可恢复任务均覆盖 |
| 111 得到额外工具、信息或预算 | 统一权限、原始信息和预算；基线可用节省预算普通重试 | 完整调用和费用记录 |
| 同一结果被多层重复引用成多份证据 | 来源编号共享；去重器在八条件中固定 | 对重复调用、重复来源计数复核 |
| 自报概率缺失被静默排除 | 缺失率、条件性分数及完整样本 Brier 上下界同时报告 | 相同公共检查点及隐藏评分 |
| 以日志先后顺序认定根因 | 最早偏差仅是诊断线索，局部替换干预另列 | 共享快照、替换规则与配对后续轨迹 |
| 模型通过反思提高自己的权限 | F 无权改规则或原始观测，认识升级需新依据 | 绕行接口、状态污染及版本竞争试例 |
| 测试时挑最好对手或最有利指标 | 最强双组件在开发集选定并冻结，主检验校正 | 预登记文件与正式结果隔离 |

第二轮检查补充了概率缺失的数学边界：总数 N、已观测平方误差和 S、缺失数 m 时，完整 Brier 只能落在 [S/N,(S+m)/N]。这避免一个方案通过拒绝报告难题概率来获得更好的表面校准分数。

## 5. 后续实验执行方案

### 阶段一：冻结问题与可测量边界

1. 明确三类任务的可完成、应停止、可补查恢复条件；隐藏验收与公开工具分开。
2. 按正文定义 C、K、F 的开关，确保关闭后仍保留原始数据、公开规则、重试及基础权限。
3. 冻结主要交互 `111 - 110 - 101 + 100`；开发集选择并冻结 H2 的最强双组件对照。
4. 选择可固定版本的模型和工具，记录提示角色、上下文限制、采样参数及模型版本。
5. 独立开发与先导家族用于估计预算和统计精度。正式 48 家族是当前规划起点，不是已验证充足样本量。

完成标准：一名接手者能够明确每个条件实际增加什么机制、允许看到什么、何种停止算成功，以及每个指标的分母是什么。

### 阶段二：实现组件与验证接口

1. 建立只追加观测、可修改认识记录和不可由模型自行改写的任务规则。
2. 实现模拟执行器，统一检查动作范围、版本和公开前置条件；外部真实权限不受实验开关影响。
3. 仅 K 开启时实现待查、冲突和已支持状态迁移；K 关闭、F 开启时反馈只输出带原始观测编号的建议，由普通执行器处理，不创建显式认识状态。反馈不能直接把假设写成事实。
4. 实现固定长度反馈和最多两轮修正，F 关闭时预算可用于普通求解。
5. 实现全部条件共用的去重、日志、资源计量与存储隔离。

必须先通过：反馈无法更改规则；工具超时不会被当成事实否定；一份来源不会被算成多份；合法任务不能因空值被机械误拒；版本核对与模拟执行原子完成；每个条件没有跨任务遗留状态。测试的是接口和评分逻辑，不能把这些检查通过写成任务效果提升。

### 阶段三：共享检查点机制实验

统一生成初始候选及公共观测，再复制给八条件。不要只保留初始错误，因为反思也可能把正确改错。隐藏验收在运行结束后评分，不能用于决定是否触发修正。候选提案、核查、反馈、状态迁移和停止原因全部记录。

在相同公共检查点收集候选正确性的概率，独立评分后计算 Brier 与缺失界限。诊断概率不能写回执行流程，诊断调用单列为研究测量成本。

完成标准：能估计从相同状态继续时的组件交互，能区分修复和新错误，且不会用局部实验冒充从零开始的效果。

### 阶段四：端到端与预算实验

从原始任务分别启动八条件，允许轨迹分化。按家族、变体、种子和运行批次配对，随机安排条件顺序，固定中心预算；随后在预先登记的低、高预算重复关键比较。

规模估计：48 家族 × 2 变体 × 8 条件 × 3 次重复，每阶段 2,304 次任务运行；共享检查点和端到端两个阶段共 4,608 次，尚未含额外预算、模型或近邻对照。每次任务可能包含多次模型与工具调用，必须用先导实际计量估算费用。该数字是拟议规模算术，不是已经运行的数量。

资源不足时，优先在正式看结果之前减少探索条件或缩减任务规模，并披露精度限制。不能删去较差结果，也不能从四条件结果声称已经识别所有三层交互。

### 阶段五：统计与独立信息判定

对主要交互和冻结的完整对双组件比较进行家族级配对估计，报告效应与 95% 区间，两项主检验采用 Holm 校正。其他交互、预算和任务层结果标明次要或探索性。若功效不足，报告区间，而不是从“不显著”推出等效。

同表报告联合成功、合法任务成功、正确停止、误拒、无依据动作、预算耗尽与所有失败成本。对关键失败做局部替换诊断时，明确使用了理想化信息，不能把诊断成绩加入真实系统总分。

最后判断是否产生新的研究信息：如果只有某单组件起作用，其他组件无增量，本稿可以报告零交互或负交互；如果研究问题和数据与配套稿完全重复，应合并为综合章节，不强行包装成另一篇独立实证论文。
