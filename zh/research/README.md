# 可靠长程智能体博士研究论文系列（7 篇）

> 最近更新：2026-10-08  
> 作者：袁成路（Chenglu Yuan），Independent Researcher，武汉  
> **当前状态：七篇「方法与研究协议初稿」已完成写作与内部自查；未执行正式实验，不含实验结果、性能数字或“已证明”结论。**

**给产品与工程读者的一句话：** 这七篇不是为了展示结论，而是为了把“可靠长程智能体”的关键机制变成可检验的课题——每篇都写清了研究问题、可反驳假设、方法规范、条件性性质（前提与不可推出的结论）以及对照实验协议；但没有实测数据之前，任何效果主张都不成立。

本系列研究一个共同问题：**当智能体需要在长任务、长历史和真实交付场景中持续工作时，如何让关键机制可检验、让结论可核对。** 七篇分别覆盖计划修正（01）、扩展边界（02）、记忆治理（03）、验证与反思（04）、证据链（05）、教育协作（06）与组件组合（07），每篇随附一份《证据核对与实验执行说明》。

## 系列分工与边界

七篇按问题和判据分工：01 验计划修正，02 验平台扩展，03 验历史适用性，04 验纠错与错误复发，05 验结论与实际完成，06 验人的无人工智能学习迁移，07 验组件交互。第 07 篇不得把第 03–05 篇的单组件效果重新包装为独立发现；若共享任务或轨迹，应共同登记、披露重叠并限定各文结论。

## 建议的推进顺序

先按 01 构建需求变化任务及验收器，冻结任务分布与记录规则；02 需冻结被比较产品的固定版本并完成真实调用，避免把文档声明当成运行能力；03–05 分别建立记忆冲突、纠错与完成声明的独立金标准；06 以成人可行性试验与适用伦理审查为前提，未成年人研究另行设计与审查。每篇先做开发集与先导试验，冻结主指标、最小有意义差异、预算和失败处理规则，再运行正式比较；取得真实数据后再依据实际发现修改题名、摘要与结论。
